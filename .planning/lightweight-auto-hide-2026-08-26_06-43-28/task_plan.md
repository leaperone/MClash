# 任务计划：轻量模式自动隐藏主窗口

## 目标

让持久化轻量模式在冷启动时保持主窗口休眠，并在可见窗口中开启后立即卸载主 UI；用户显式点击 App、菜单栏 Open 或打开 URL 时仍可恢复窗口。

## 成功标准

- 普通冷启动在 `application.lightweightMode=true` 时不展示主窗口。
- 可见窗口开启轻量模式后立即 `orderOut`，同步停止展示遥测并隐藏 Dock。
- 第二实例的显式启动请求仍能唤起已经运行的轻量实例。
- 现有生命周期、类型检查与构建检查通过，diff 无格式错误。

## 边界

- 不做完全 headless 模式，保留静态菜单栏 Open/Quit。
- 不改变关闭轻量模式时是否自动打开窗口的现有语义。
- 不处理 View-local 草稿持久化，也不新增测试或手工 UI 测试。
- 不发布、安装或替换当前运行中的 System Extension。

## 步骤

1. 复用现有启动判定并区分首次展示与第二实例显式唤起。
2. 在既有 `setLightweightMode` 状态机中隐藏可见主窗口。
3. 运行范围相称的自动验证并审查完整 diff。
4. 提交、推送、创建 PR 并执行 preflight。
