# MClash 1.6.0-rc.9

这是 MClash 1.6 的第九个测试版本。MClash 负责节点来源、节点、节点组、规则、DNS、入口和连接记录，Xray-core 只负责协议连接和转发。

- 1.6 的应用包只包含 Xray-core。旧的 mihomo 可执行文件、对应源码包和第三方说明不会进入 1.6 Xray 发布包。
- 除订阅外，可以直接粘贴节点分享链接添加节点。支持多行粘贴、剪贴板导入、导入预览、重复检测和失败行诊断。WireGuard 原生配置文本、Base64 编码节点列表和远程 Base64 来源也会自动识别。
- 支持 VLESS、VMess、Trojan、Shadowsocks、HTTP、SOCKS5、Hysteria2 和 WireGuard 分享链接。无法安全验证的节点会单独显示诊断，不会拖垮整份配置。
- 连接记录由 MClash 读取 Xray access log 后保存和展示。连接列表、连接数摘要和自动化接口都使用这条记录链路。记录代表连接事件，不代表完整的单连接字节统计，也不能从记录页面关闭已经建立的连接。
- 连接记录和运行状态文案已改为普通用户可以理解的“连接记录”“代理服务”和“路由详情”，不再把旧核心名称显示给用户。

此版本用于测试，不进入稳定版自动更新。需要 Apple Silicon 和 macOS 14 或更新版本。

本地已验证 Xray HTTP 和 SOCKS5 入口、节点组选择、URL-test、Fallback、恢复、Load Balance、Relay、DNS、WireGuard schema、失败激活回滚、直链来源持久化、连接记录查询、连接数摘要和 Xray 记录关闭操作的明确拒绝。完整测试和应用验收证据见 `ReleaseEvidence/1.6.0-rc.9.json`。

真实 Developer ID 签名、公证、Gatekeeper、生产 Network Extension 接管、Fake-IP、远程规则集刷新和每个机场节点的互通性仍由发布工作流和后续实机验收负责。
