# MClash 1.5.5

This patch carries native DNS policy through the complete query path.

- DNS policy rules are included in the connector-neutral bootstrap, parsed
  from the first bounded DNS question, and used to select a literal-IP
  upstream for both native UDP and TCP DNS relays.
- Query names are normalized with label and length bounds; malformed or
  unsupported policy targets fall back to the declared upstream order rather
  than being guessed.
- Native rule-set refresh, entrance controls, proxy-group priority summaries,
  stable traffic history, and terminal observation handling from 1.5.4 remain
  intact.

The native DNS policy does not resolve nameserver hostnames, and fake-IP,
GEOIP/GEOSITE databases, URL YAML/MRS rule providers, Reality/XTLS, and full
Hysteria2 wire interoperability remain explicit follow-up boundaries.
