# MClash 1.5.1

This fix-forward patch restores the GitHub release workflow YAML parsing and
keeps the native-only 1.5.x packaging and runtime boundaries from 1.5.0.

- Imported profiles remain node/source metadata only; MClash owns entrances,
  routing rules, DNS, and proxy-group composition.
- Native HTTP/SOCKS listeners, App Routing capability separation, terminal
  Direct/Reject handling, native DNS, connector capability gates, and bounded
  traffic observations are unchanged and covered by the direct harness.
- The release workflow now parses the distribution marker correctly before
  selecting native-only assets.

The production `/Applications/MClash.app` is not modified by validation or
release preparation.
