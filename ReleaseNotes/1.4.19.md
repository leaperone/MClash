# MClash 1.4.19

- Add the MClash-owned HTTP CONNECT codec used by the new inbound listener
  path, with bounded header parsing and safe 200/502 responses.
- Keep routing decisions separate from outbound connector invocation; Mihomo is
  used only through the connector boundary for proxy routes.
- Preserve direct handling for LAN, Parsec, and other native connections.

This is an architecture migration patch; existing Mihomo listener compatibility
remains while the MClash-owned listener is rolled out and shadow-tested.
