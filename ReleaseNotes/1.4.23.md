# MClash 1.4.23

This patch keeps everyday node editing on one screen and stops upgrades
from replacing a readable strategy document with a blank default.

- Edit a node group in place on the Nodes page: pick the group, then
  change members in the main pane instead of a right-hand inspector.
- Keep the live configuration when an upgrade cannot decode one older
  rule field. Only true non-JSON garbage is quarantined. Copies already
  moved aside under Application Support are left in place.

The release is Apple Silicon-only. MClash still does not enable TUN by
default.
