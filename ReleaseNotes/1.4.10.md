# MClash 1.4.10

This fix-forward patch completes node-only workspace adoption after a source
refresh.

## Dynamic node scope

- Migrate an older workspace that explicitly listed every enabled catalog node
  to the dynamic all-enabled scope.
- Include source-removed catalog records when recognizing that legacy all-node
  representation, so a stale record cannot make it look user-narrowed.
- Preserve genuinely narrowed node scopes unchanged while allowing newly
  imported subscription nodes to join all-node workspaces automatically.
