# MClash 1.4.15

This patch tightens unified routing and removes the repeated local socket
authorization prompt.

- Treat the private same-user Unix socket as trusted after UID, permissions,
  and peer-process checks; `mclashctl` no longer needs pairing or recurring
  authorization prompts.
- Add MClash-owned LAN bypass rules for loopback, private IPv4/IPv6 ranges,
  and link-local traffic so Docker, SSH, printers, and local services stay
  direct when App Routing is enabled.
- Seed editable China, private-network, GFW/GeoSite, and ad-block rule sets in
  new and migrated workspaces.
- Rebuild the common strategy groups from fixed CUNOE-Proxy nodes, preserving
  the original priority order while excluding AWS, Taiwan, subscription-notice,
  and unrelated-source nodes. Temporarily missing pins safely fall back to
  DIRECT instead of creating invalid groups.
- Remove the visual gap between DNS and Rules in the Configuration sidebar.

The release remains Apple Silicon-only, uses the bundled Mihomo Alpha core, and
does not enable TUN.
