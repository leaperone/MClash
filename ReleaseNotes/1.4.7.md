# MClash 1.4.7

This fix-forward patch applies the unified-runtime handoff and node import
repairs on top of the 1.4.6 automation release.

## Unified runtime handoff

- Automatically adopt a populated MClash configuration once after upgrade.
- Keep imported profiles as node sources only; their provider-owned groups,
  rules, DNS, listeners, and controller settings are not used for runtime.
- Migrate legacy App Routing rules into the unified Rules workspace with stable
  IDs, source-scoped node groups, and review diagnostics for unsupported
  application identities.
- Preserve the prior runtime and manifest when migration or kernel activation
  fails; migration completion is recorded only after successful activation.

## Node import and Mihomo compatibility

- Preserve nested `ws-opts`, `reality-opts`, headers, and YAML list/map values
  while importing subscription nodes.
- Support inline proxy sequences and wider valid YAML indentation styles.
- Repair empty nested-field placeholders created by the first 1.4.5 importer
  without changing pinned node identities.
- Emit valid Mihomo composite rules for combined domain, port, and transport
  matchers, and retain the managed Mixed listener in compiled runtime output.

## Verification

- Direct typecheck, full unit suites, integration smoke tests, and bundled
  Mihomo `-t` validation passed against the migrated local catalog.
