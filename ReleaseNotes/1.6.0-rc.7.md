# MClash 1.6.0-rc.7

这是 1.6 的第七个测试版本。MClash 继续负责来源、节点、节点组、规则、DNS、入口和流量记录，Xray-core 只负责协议连接和转发。

- 除订阅外，可以直接粘贴节点分享链接添加节点。常见的 `socks://` 和 `socks5://` 链接都会识别为 SOCKS5 节点。支持多行粘贴、剪贴板导入、导入预览、重复检测和失败行诊断；WireGuard 原生配置文本和 Base64 编码节点列表也会自动识别，每个 Peer 会生成一个节点；远程来源返回 Base64 节点列表时也会正确导入；导入的节点会保存在本机。
- 支持 VLESS、VMess、Trojan、Shadowsocks、HTTP、SOCKS5、Hysteria2 和 WireGuard 分享链接。TUIC、未知协议以及未识别的传输插件会显示不支持原因，不会静默改用其他核心。
- “流量记录”由 MClash 汇总。Xray 的 access log 会转换为时间、入口、目标、传输方式和出口记录；App Routing 记录仍单独提供应用、规则和生命周期信息。
- 连接记录页面已补齐多语言文案，并标明数据来源和字段范围。Xray access log 没有应用身份或完整的单连接字节统计时，界面不会把这些字段伪装成已知数据。
- 修复发布流程在 macOS 磁盘映像校验瞬态失败时过早退出的问题。Xray 26.9.9 已移除 `allowInsecure` 导致整份配置无法启动的问题。无法安全验证的节点会单独显示诊断，不再拖垮其他节点。
- 产品界面继续使用“节点来源”“连接方式”“节点组”“流量记录”等普通用户可以理解的称呼。

此版本用于测试，不进入稳定版自动更新。需要 Apple Silicon 和 macOS 14 或更新版本。

已验证 Xray 入口、SOCKS5、节点组选择、URL-test、Fallback、恢复、Relay、DNS、WireGuard outbound schema、失败激活回滚、直链来源持久化，以及从 Xray access log 读取连接记录。完整测试和应用验收证据见对应的 `ReleaseEvidence/1.6.0-rc.7.json`。

Developer ID 签名、公证、Gatekeeper 检查和下载包隔离验收已完成。真实 Network Extension 接管、Fake-IP、远程规则集刷新和每个机场节点的互通性不由本次验收推断。
