# MClash 1.4.4

This patch packages the compact proxy workflow and localization improvements
from the 1.4.x line and restores a reliable release verification path.

## Daily proxy controls

- Switch Rule, Global, and Direct modes directly from the Proxies toolbar.
- Keep More actions compact and place lower-frequency commands behind the
  trailing icon button.
- Make every menu-bar action one step away without expandable sections.

## Localization and configuration safety

- Keep dynamic status, error, routing, profile, automation, and diagnostic
  text consistent across all supported languages.
- Preserve the compiled Workspace during reconnects and App Routing updates.
- Reject invalid configuration dependencies and retain the previous working
  configuration when save or activation fails.

## Release verification

- Keep Core, System Proxy, Mihomo API, and optional Profile integration smoke
  targets linked with the app's existing localization implementation.
