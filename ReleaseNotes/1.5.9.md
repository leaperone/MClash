# MClash 1.5.9

This patch moves entrance activation and DNS attribution further into the
MClash-owned native runtime while keeping unsupported capabilities explicit.

- App Routing is now an ordinary editable entrance. It shares the same
  activation model as HTTP, SOCKS5 and System Proxy instead of appearing as a
  separate global switch.
- Native System Proxy and App Routing transitions use one transactional
  lifecycle. Failed replacements restore the prior entrance state, and the UI
  reports the observed state rather than the requested state.
- TUN remains visible as an entrance capability but cannot be enabled until its
  native packet path has interoperability evidence. This release never turns
  TUN on implicitly.
- Native DNS now records bounded, in-memory A/AAAA and CNAME associations and
  uses them only to supplement IP-only flows from the same signed application,
  configuration revision and runtime generation. Ambiguous or expired mappings
  are ignored, while the original IP remains available for GEOIP matching.
- DNS attribution is capped globally and per application, clamps TTLs to a
  short lifetime, rejects malformed compression and mismatched answer families,
  and is cleared on provider start, stop and live configuration replacement.
- Native Fake-IP mode now fails before activation with an actionable message.
  MClash does not silently run it as Redir Host while the allocator and reverse
  mapping data plane are unfinished.
- The macOS 26 typed-QUIC Hysteria2 probe now has bounded, stage-specific
  diagnostics and independent stream lifecycle handling. Hysteria2 remains an
  explicit unsupported/fallback capability because a real endpoint has not yet
  completed the QUIC connection and HTTP/3 authentication proof.
- Release tests still run on the free standard `macos-26` runner. Network test
  files are executed in bounded four-file child processes, reducing repeated
  compiler/link work without filtering or dropping test coverage.

Validation passed 554 application tests, all 37 Network Shared and 13 Network
Extension test files, six automation tests, the compatibility integration
smoke, and release preflight. A native-only `1.5.9` shadow copied the current
local Profile configuration, loaded workspace revision 31, started all three
enabled loopback socket entrances, reported both GeoIP and GeoSite ready, and
used a bundle with no Mihomo binary or control plane. A real CUNOE VLESS WebSocket route
through the MClash-owned HTTP entrance returned Google `204`.
