# MClash 1.5.8

This patch completes native activation for the bundled v2fly GEO databases and
hardens cached text rule sets.

- Native routing now reads both `GeoIP.dat` and `GeoSite.dat`, dispatching
  GEOIP and GEOSITE matches to independent indexed providers.
- GeoSite supports Plain, RootDomain, Full and precompiled Regex entries. The
  bounded decoder rejects malformed UTF-8 and oversized data, skips supported
  unknown protobuf fields, and merges repeated categories.
- Workspace activation checks each required GEO kind. A missing GeoIP or
  GeoSite database rejects the candidate and preserves the last known-good
  native session instead of silently falling through to another rule.
- Runtime diagnostics expose separate `geoDatabases.ip` and
  `geoDatabases.site` status while keeping the existing aggregate field.
- Refreshed HTTPS text rule sets can retain their source URL for provenance and
  load the atomically written local cache during native activation.
- The app can restore the requested connection during background launch without
  waiting for the main window, while native mode no longer requires a legacy
  generated YAML path to exist.
- Node groups use a persistent list-and-editor layout with full-row hit targets,
  in-place membership editing, explicit deletion controls, and the existing
  fixed-node/automatic-matcher guidance.
- Strategy documents are preserved when a newer or temporarily incompatible
  decoder cannot open them, preventing an upgrade from replacing user policy
  with an empty default.

Validation used the real bundled GeoIP and GeoSite snapshots, a copied-profile
native shadow with three running loopback listeners, and a real CUNOE VLESS
WebSocket route to Google (`204`). GeoSite attributes, metadb/MMDB, YAML/MRS
rule-set providers, Reality/XTLS, and full Hysteria2 interoperability remain
explicit follow-up work.
