# MClash 1.3.5

This patch reduces background work and tightens flow handling across the app
and Network Extension, especially while MClash is idle or a window is hidden.

## Runtime efficiency

- Combines lightweight-mode runtime heartbeats and pauses unnecessary checks
  while the Mac is sleeping or the app is not visible.
- Avoids redundant TCP/UDP relay dispatches and uses constant-time UDP queue
  dequeues for lower overhead under load.
- Reuses DNS identity results and caches transient process-identity failures to
  reduce repeated resolver and process lookups.

## Flow and routing safety

- Bounds active TCP relays and UDP session admission so resource usage remains
  predictable during bursts.
- Streams App Routing candidate matching and skips unnecessary wildcard work
  for literal application identifiers.
- Keeps lightweight mode's window and menu-bar behavior consistent when the
  main window is hidden.
