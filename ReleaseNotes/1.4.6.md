# MClash 1.4.6

This patch adds agent-friendly configuration automation to MClash while
keeping sensitive connection details out of the automation surface.

## Agent automation

- Install the bundled `mclashctl` command through a safe user-level PATH
  symlink without modifying shell profiles or overwriting unrelated files.
- Use one absolute deadline for Unix-socket connect, write, and read, with
  machine-readable request IDs, failure stages, and safe retry guidance.
- Inspect, plan, apply, delete, and activate configuration through bounded
  APIs with compare-and-swap revisions, selector export, and activation
  recovery.

## Configuration safety

- Keep snapshots redacted and editable updates sparse so hidden credentials and
  runtime-only state are never round-tripped through the Agent API.
- Validate generated configuration before persistence and keep workspace scope
  explicit so clearing a node list cannot silently broaden its selection.
- Complete the unified Configuration workbench localization across all eight
  supported languages.
