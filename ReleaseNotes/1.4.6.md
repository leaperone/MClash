# MClash 1.4.6

This patch completes the node-only configuration handoff for existing
installations and fixes runtime validation for modern Mihomo transport fields.

## Unified configuration handoff

- Automatically adopt a populated MClash configuration once after upgrade.
- Keep imported profiles as read-only node sources; their groups, rules, DNS,
  listeners, and other policy sections are not used as the runtime authority.
- Migrate legacy App Routing rules into the unified Rules workspace with stable
  IDs, source-scoped node groups, and review diagnostics for anything that
  cannot be represented safely.
- Preserve the previous runtime and configuration document when migration or
  kernel validation fails.

## Import and runtime validation

- Preserve nested ws-opts, reality-opts, headers, and other YAML maps/lists
  when importing nodes, including inline and wider-indentation YAML forms.
- Render combined domain, port, and transport rules using Mihomo's valid
  composite AND/OR syntax.
- Repair earlier empty nested-field placeholders without changing pinned node
  identities.

## Agent automation

- Install the bundled mclashctl command through a safe user-level PATH
  symlink without modifying shell profiles or overwriting unrelated files.
- Use bounded, machine-readable configuration inspection, planning, apply,
  delete, and activation operations with compare-and-swap revisions.
- Keep automation snapshots redacted and validate generated configuration
  before persistence.
