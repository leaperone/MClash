# MClash 1.4.5

This patch introduces the unified configuration workbench and makes imported
profiles behave as node sources instead of policy containers.

## Unified configuration

- Keep Configuration, Rules, Nodes, Sources, Entrances, DNS, and Node Groups
  in one native macOS Sidebar/List/Inspector workspace.
- Keep App Routing out of the sidebar and manage it as the Application traffic
  switch inside Entrances.
- Manage application, process, domain, IP/CIDR, transport, and port matching in
  the first-level unified Rules editor.
- Add selector-based Node Groups with wildcard conditions, exclusions, and
  durable fixed-node pins instead of per-node toggle lists.

## Safer source refreshes

- Import only node connection data from source profiles; source groups, rules,
  DNS, TUN, and other strategy sections are ignored by the MClash compiler.
- Derive stable node identities from normalized endpoint fingerprints so name
  changes and rotating credentials do not orphan group membership.
- Preserve prior nodes on partial parsing or source read failures, retain
  explicit conflict diagnostics, and recompile the unified runtime after a
  successful source refresh.

## Usability and verification

- Add and edit HTTP, SOCKS5, and TUN entrances with port and default-action
  validation.
- Improve compact-window Inspector behavior, localized workbench copy, and
  source metadata privacy.
- Verified direct typecheck, unit suites, integration smoke tests, localization
  lint/parity, and Mihomo controller/HTTP/SOCKS runtime smoke coverage.
