# MClash 1.3.3

This patch completes live App Routing updates for rules that add or remove
Profile, GLOBAL, policy-group, or node-backed routes.

## Connection-preserving route updates

- Adds missing private Mihomo listeners through the affected Profile's
  authenticated controller instead of restarting Primary or Auxiliary cores.
- Keeps existing listener endpoints, credentials, and stable identity-based
  names unchanged for the lifetime of a running session.
- Retains removed routes as an idle listener superset until the next cold
  start, so existing Transparent and DNS relays remain valid.
- Verifies dual-stack authenticated SOCKS5 and UDP listener ownership before
  committing a live runtime configuration.

## Non-destructive rollback

- Restores rejected rule and Provider updates through a newer live revision
  without disconnecting Mihomo sessions.
- Rejects any candidate that would move or remove an endpoint still usable by
  an existing relay instead of falling back to a full Provider restart.
- Keeps pre-existing Auxiliary cores online when post-reload verification
  fails, while still stopping a newly started session that never became valid.

## Dedicated proxy ports

- Refreshes live Profile proxy catalogs when choosing a target so provider
  nodes appear when their Profile controller is available.
- Distinguishes configured but currently unavailable ports from live copyable
  proxy addresses in Settings.
