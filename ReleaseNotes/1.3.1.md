# MClash 1.3.1

This patch makes multi-profile routing easier to understand and keeps the
Proxies workspace stable while moving between profiles and views.

## Multi-profile behavior

- Adds a stable virtual **Default Profile** with its own Mixed port. Changing
  the profile that backs Default no longer changes the address used by system
  proxy settings and existing clients.
- Gives every imported profile its own dedicated Mixed port. That port can be
  opened or closed independently without disabling the virtual Default Profile.
- Preserves existing listener addresses during migration and validates every
  Default, profile, controller, and App Routing port before activation.

## Proxies and App Routing

- Lets the Proxies tab switch freely between profiles and edit each profile's
  own policy-group selections, overrides, and delay results.
- Keeps the Proxies command bar in fixed positions when switching between List
  and Topology, changing profiles, sorting, testing, or showing the inspector.
- Adds quick profile management to App Routing so the Default source and
  dedicated profile ports can be changed without leaving a rule draft.

## Traffic visibility

- Merges Traffic, Processes, routes, history, and rate totals by default.
- Adds explicit filters for Default Profile, individual profiles, and
  Direct/System traffic while preserving profile attribution.
