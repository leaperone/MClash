# MClash 1.3.8

This patch keeps everyday proxy controls direct and makes operational text
consistent across all eight supported languages.

## Faster proxy control

- Puts Rule, Global, and Direct mode switching directly in the Proxies toolbar.
- Keeps More buttons compact and reserves their menus for lower-frequency actions.
- Removes collapsible routing sections from the menu bar so every action is one step away.

## Broader localization

- Localizes more dynamic status, error, routing, profile, automation, and diagnostic text.
- Makes dates, numbers, and traffic values follow the language selected in MClash.
- Completes the English source catalog and aligned translations for all supported locales.
