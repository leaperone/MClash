# MClash 1.4.8

This patch hardens node-only subscription import for common Clash YAML
variants.

## Node import

- Accept indentationless root-level `proxies` sequences, while still stopping
  at the next root strategy section.
- Keep imported profiles node-only; provider-owned groups, rules, DNS and
  controller settings remain excluded from the MClash runtime.

## Verification

- Direct tests, typecheck, and `git diff --check` passed.
