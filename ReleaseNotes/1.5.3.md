# MClash 1.5.3

This patch continues the native runtime migration while making the main
configuration workflow easier to understand and safer to operate.

- Entrances now present macOS System Proxy and App Routing together as entry
  points. App Routing is no longer duplicated as a hidden rule-side switch;
  named HTTP, SOCKS5, and TUN entries remain editable in the workbench.
- Native diagnostics hide retained legacy listener details. A native runtime
  never creates or advertises an imported `mixed-port`/`allow-lan` listener.
- Inline rule sets preserve explicit targets, and local classical text sets
  can be loaded with a bounded 4 MiB parser. URL/YAML/MRS providers remain
  explicit compatibility boundaries until their native loaders are complete.
- Traffic quick-rule suggestions are deduplicated and stable, flow history has
  deterministic paging, and active observations are terminally closed when a
  runtime stops.
- Concurrent Hysteria2 authentication is coalesced at the transport boundary;
  this improves correctness without claiming full Hysteria2 wire support.

The distribution remains native-only and does not ship a Mihomo executable.
The production `/Applications/MClash.app` is not modified by validation.
