# MClash 1.4.9

This patch fixes unified startup against large migrated rule sets and validates
the generated document with the bundled Mihomo parser.

## Unified migration

- Accept legacy rules with thousands of domain matchers while retaining
  deterministic per-rule, workspace, plan and compiled-size safety limits.
- Restore the prior App Routing snapshot if unified compilation or activation
  fails, using a safely advanced revision.
- Preserve disabled rules still referenced by another configuration when the
  current configuration adopts migrated App Routing rules.

## Mihomo compatibility

- Emit YAML-compatible `/` characters instead of JSON-only `\/` escapes in
  node names, group members and CIDR rules.
- Preserve `DOMAIN-WILDCARD` semantics instead of weakening wildcard rules to
  `DOMAIN-KEYWORD`.
- Add an integration smoke that compiles nested Reality/WebSocket transports,
  selector-backed groups, logical rules, DNS and entrances, then runs the
  exact bundled Mihomo binary with `-t` on the generated YAML.
