# MClash 1.3.2

This patch adds dedicated local proxy ports for predictable per-profile and
per-route egress, and makes ordinary App Routing rule edits apply without
restarting Mihomo or dropping existing connections.

## Dedicated routing ports

- Create multiple local HTTP, SOCKS5, or Mixed proxy entrances, each with its
  own stable loopback port.
- Bind every entrance to a Profile and follow its normal rules, enter a named
  sub-rule, use Mihomo GLOBAL, or pin traffic to a policy group or proxy node.
- Validate Profile targets, protocols, port conflicts, and live HTTP/SOCKS5
  handshakes before accepting a running configuration.
- Keep dedicated entrances local to this Mac on IPv4 and IPv6 loopback.

## App Routing reliability

- Apply matcher, priority, enable/disable, and same-route action changes live
  while Mihomo and existing Transparent/DNS relays stay connected.
- Refresh DNS Routing through the verified provider channel without toggling
  the DNS proxy off and on.
- Roll back rejected DNS bootstrap replacements cleanly so the same revision
  can be retried instead of being mistaken for an active configuration.

## Automation and settings

- Manage and inspect dedicated routing ports from Settings.
- Include the new listener state in automation status output and Profile plan
  persistence, including migration from existing saved plans.
