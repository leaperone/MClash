# MClash 1.5.0

MClash 1.5.0 makes the native runtime the authoritative path for the new
configuration model. Imported profiles provide node and source metadata;
MClash owns entrances, routing rules, DNS, and proxy-group composition.

Highlights:

- Native HTTP and SOCKS entrances bind only configured loopback sockets in an
  isolated runtime and keep App Routing as a capability rather than a hidden
  side switch.
- Direct and Reject decisions terminate in MClash. Native routing and DNS no
  longer silently fall back to Mihomo; unsupported transports report an
  explicit legacy-fallback reason.
- CUNOE-scoped regional groups, stable node identity, matcher-based membership,
  fixed members, and deterministic priority ordering are preserved across
  subscription refreshes.
- Native observations feed the bounded flow ledger with route-chain metadata,
  terminal lifecycle states, and reconnect-safe monitoring updates.
- The 1.5.x distribution is native-only and does not ship a Mihomo binary,
  source tarball, or Mihomo license asset.

Validation was performed with the direct macOS harness (532 application tests,
35 shared targets, 12 Network Extension targets, automation tests, and release
preflight), an isolated native-only build, and a copied-profile shadow run.
The production `/Applications/MClash.app`, its Mihomo process, system proxy,
and installed Network Extension are not modified by the release checks.

Known explicit compatibility boundaries remain: Reality/XTLS wire support,
full Hysteria2 HTTP/3 interoperability, Shadowsocks UDP/plugins, split DNS and
fake-IP, complete GEOIP/GEOSITE rule-set operations, and final Rockxy-style UI
polish are scheduled for subsequent releases rather than being misrepresented
as implemented here.
