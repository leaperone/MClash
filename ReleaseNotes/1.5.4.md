# MClash 1.5.4

This patch makes the native configuration workflow more useful without
silently widening the compatibility boundary.

- HTTPS classical text rule sets can be refreshed from the Configuration UI
  into a private, atomically replaced MClash cache. Native activation uses the
  cached snapshot and restores the previous policy if recompilation fails.
- Native DNS policy projection now provides deterministic longest-suffix
  matching for literal nameserver targets and reports unsupported destinations
  explicitly.
- The Entrances page keeps macOS System Proxy and App Routing together as
  first-class entry points; proxy-group editing shows automatic/fixed counts
  and fixed-node priority instead of a wall of switches.
- Native diagnostics continue to hide legacy mixed-port listeners, and flow
  monitoring retains stable quick-rule ordering and terminal observations.

URL rule sets with no cached text snapshot, YAML/MRS providers, GEO databases,
Reality/XTLS, and full Hysteria2 wire interoperability remain explicit future
work; this release does not claim those capabilities.
