# MClash 1.4.11

This fix-forward patch validates node-only configuration against real local
profiles and makes large proxy-group workflows practical.

## Mihomo compatibility

- Preserve quoted scalar types inside imported nested proxy options, including
  numeric-looking REALITY short IDs that Mihomo requires to remain strings.
- Validate compiler smoke tests with the bundled offline GEO snapshot instead
  of relying on a network download during startup.
- Exercise nested select, fallback, and URL-test groups with the bundled Mihomo
  Alpha core.

## Common strategy groups

- Add an optional MClash-owned group set with one stable Node Selection entry,
  Hong Kong, United States, and Japan priority groups, failover, residential,
  manual, automatic, and direct choices.
- Redirect proxy actions in the selected configuration through Node Selection
  while preserving direct and reject rules and isolating rules shared by other
  configurations.
- Keep regional membership dynamic across subscription refreshes; imported
  profile groups, rules, DNS, and TUN sections remain ignored.

## Large node libraries

- Separate automatic matching conditions from fixed node pins in the editor.
- Add search, bounded previews, match counts, bulk pinning, keyboard and
  VoiceOver actions, and independently scrolling fixed-node results.
