# MClash 1.6.0-rc.11

这是 MClash 1.6 的第十一个测试版本，修复了 Xray 规则数据库在真实运行目录中无法加载的问题。

- Xray 26.9.9 的 `geoip.dat` 和 `geosite.dat` 现在从固定版本的 Xray 发布包提取，并随 1.6 Xray 包发布。
- Xray 私有运行目录只安装小写 GEO 数据库。旧版本仍保留旧的 GEO 数据路径，两个运行时不会互相覆盖。
- 使用 `geoip:cn` 和 `geosite:cn` 的真实 Xray 配置检查已通过。应用包仍只包含 `mclash-xray`，不包含旧核心。
- 连接记录继续由 MClash 读取 Xray access log 后保存和展示。记录代表连接事件，不代表完整的单连接字节统计。
- 简体中文和繁体中文界面继续使用“代理服务”“规则”“连接记录”和“全部流量”等产品词。

此版本用于测试，不进入稳定版自动更新。需要 Apple Silicon 和 macOS 14 或更新版本。

本地已验证 Xray GEO 规则、HTTP 和 SOCKS5 入口、节点组选择、URL-test、Fallback、恢复、Load Balance、Relay、DNS、失败激活回滚、连接记录查询和 Xray-only 包布局。完整测试和应用验收证据见 `ReleaseEvidence/1.6.0-rc.11.json`。

真实 Developer ID 签名、公证、Gatekeeper、生产 Network Extension 接管、Fake-IP、远程规则集刷新和每个机场节点的互通性仍由发布工作流和后续实机验收负责。
