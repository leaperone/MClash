# MClash 1.5.10

This patch makes the native MClash runtime the default for ordinary launches.
The application now compiles and activates its connector-neutral workspace
plan without starting a Mihomo process; `MCLASH_LEGACY_RUNTIME=1` remains an
explicit rollback switch for compatibility testing.

Native DNS relay responses now use a bounded, transaction-ID-safe cache shared
by the provider's TCP and UDP paths. Entries expire after 30 seconds and are
evicted FIFO at the 256-entry limit.

The native-only build contains the app, CLI, Network Extension and verified GEO
databases without a Mihomo executable. Unsupported transports continue to be
reported as explicit capability fallbacks.
