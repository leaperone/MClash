# MClash 1.4.14

This patch fixes unified-runtime startup and clarifies the configuration
workbench.

- Repair stale managed Mixed-port collisions with named HTTP/SOCKS entrances;
  a node-only source without `mixed-port` is no longer treated as a broken
  runtime.
- Keep mainland-China `GEOSITE,cn` and `GEOIP,CN` traffic direct before the
  proxy catch-all.
- Scope the common regional strategy groups to CUNOE-Proxy nodes and prevent
  cross-region duplication after subscription refreshes.
- Put Entrances first in navigation and show macOS System Proxy/App Routing as
  entrance capabilities, with Traffic live/paused snapshots and quick rule
  actions retained in the workbench.
- Add a development-only isolated instance mode for testing without touching a
  production MClash installation.

The release is Apple Silicon-only and requires the bundled Mihomo Alpha core.
