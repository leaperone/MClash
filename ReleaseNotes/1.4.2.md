# MClash 1.4.2

This maintenance release fixes the unified Workspace runtime activation path
introduced in MClash 1.4.

- Reconnects and runtime activation now keep the compiled MClash Workspace
  configuration authoritative instead of reapplying legacy profile YAML.
- HTTP and SOCKS5 entrance ports remain enabled when a unified Workspace is
  active, and listener conflict checks use the generated configuration.
- No changes to the MClash 1.4 configuration model or native workbench UI.
