# MClash 1.4.22

This patch sharpens everyday navigation and lands the remaining 1.4.19
routing fixes on main.

- Put Status, Subscriptions, Nodes, How to Connect, and Connection Log
  first in the sidebar, menu bar, and Navigate menu so common tasks stay
  one click away.
- Keep Parsec (`tv.parsec.www`) on the native App Routing direct path,
  verify that rule in the capture plan, and preserve 1.4.20 split-traffic
  listener pins when the unix-socket routing fixes land.
- Make chevron rows open their action across the full row in the menu bar,
  node list, topology cards, and profile picker.

The release is Apple Silicon-only. MClash still does not enable TUN by
default.
