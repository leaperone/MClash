# MClash 1.6.0-rc.13

这是 MClash 1.6 的第十三个测试版本，补齐从旧测试版升级时的 Xray GEO 数据迁移。

- 如果私有运行目录里已有旧的 `GeoIP.dat` 或 `GeoSite.dat`，MClash 会核对 SHA256，并用 Xray 26.9.9 的原生小写数据库替换不匹配的旧文件。
- 全新安装和升级安装都能加载 `geoip:cn` 与 `geosite:cn` 规则。
- Xray 二进制和 GEO 数据从固定版本发布包提取并逐项校验。
- 应用包只包含 `mclash-xray`，不包含旧核心。连接记录继续由 MClash 管理。
- 简体中文和繁体中文界面继续使用产品化中文词汇。

此版本用于测试，不进入稳定版自动更新。需要 Apple Silicon 和 macOS 14 或更新版本。

本地已验证 517 项应用测试、旧 GEO 数据升级替换、Xray GEO 规则、HTTP 和 SOCKS5 入口、节点组策略、DNS、连接记录和 Xray-only 包布局。完整证据见 `ReleaseEvidence/1.6.0-rc.13.json`。

真实 Developer ID 签名、公证、Gatekeeper、生产 Network Extension 接管、Fake-IP、远程规则集刷新和每个机场节点的互通性仍由发布工作流和后续实机验收负责。
