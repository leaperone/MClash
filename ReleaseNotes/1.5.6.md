# MClash 1.5.6

This patch makes the native state and its limits visible in the product UI.

- Overview and Entrances now show macOS System Proxy beside the workspace
  entrances, with a clear On/Off state; retained legacy Mixed listeners are not
  presented as user entrances.
- Native GEO rules have a provider/status capability boundary. A future native
  database reader can report `ready`; unavailable or unsupported data is no
  longer allowed to masquerade as a non-match when enforcement is enabled.
- The native DNS suffix policy, bounded text rule-set refresh, stable traffic
  inspector/history, and native listener lifecycle fixes remain included.

No guessed `.dat`, `.metadb`, or `.mrs` parser is shipped. GEO database
interoperability, Reality/XTLS, and full Hysteria2 wire support remain explicit
follow-up work.
