# MClash 1.3.7

This patch makes everyday proxy controls easier to understand while keeping
advanced routing and diagnostics available when needed.

## Clearer daily workflow

- Reorders the main navigation around status, profiles, proxy selection,
  traffic, and app routing, with troubleshooting tools grouped under Advanced.
- Refocuses Overview and the menu bar on the current state, the next useful
  step, and one primary action instead of duplicating the full control surface.

## Less default complexity

- Reduces always-visible table columns and controls across Traffic, Proxies,
  App Routing, Rules, Providers, Profiles, Logs, and Settings.
- Moves technical details and low-frequency actions into existing inspectors,
  disclosure sections, details views, and More menus without removing features.
- Simplifies subscription and rule setup by asking for essential information
  first and revealing optional or advanced fields only when relevant.

## Accessible guidance

- Keeps recovery actions and validation messages visible when they matter.
- Improves VoiceOver labels, validation focus, copy feedback, and control hit
  areas across configuration and routing workflows.
