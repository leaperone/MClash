# MClash 1.4.12

This patch release moves imported profiles to a node-only source model and
makes the MClash configuration the single owner of routing policy.

- Added explicit Rule, Global, and Direct routing modes with a stable GLOBAL,
  DIRECT, and REJECT policy surface.
- Added named, independently targeted HTTP and SOCKS5 entrances. App Routing
  is presented as an entrance switch rather than a second rule editor.
- Added selector-based node groups with wildcard/source/protocol/tag matching,
  fixed pins, nested groups, and visible priority ordering. The Node Selection
  setup includes US, JP, HK, automatic, manual, failover, residential, and
  direct groups.
- Added first-class MClash Rules and Rule Sets for app/process, domain,
  IP/CIDR, port, GEOIP, GEOSITE (including `gfw`), and Mihomo provider formats.
  IPv6 networks use `IP-CIDR6`; unsupported `GEOIP6` is rejected clearly.
- Reworked Traffic into stable live/paused snapshots with an inspector and
  reviewed quick actions for domains, applications, and processes.
- Clarified source/workspace/runtime/entrance status and stopped presenting
  the internal Mixed recovery socket as a user policy. Imported source rules,
  groups, DNS, TUN, listeners, and controllers are not executed by the unified
  runtime.
- Hardened Mihomo validation, listener cleanup, disabled Rule Set handling,
  node identity reconciliation, and rollback before activation.

The release is Apple Silicon-only and requires the bundled Mihomo Alpha core.
