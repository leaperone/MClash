# MClash 1.4.20

This patch ships the split-traffic workbench from main.

- Give Entrances two everyday paths: a copyable local HTTP/SOCKS address
  for a browser extension, and App Routing for selected Mac apps, each
  using a different subscription’s nodes.
- Keep unlisted apps on Direct, leave leftover listeners under Advanced,
  and require Rule mode plus Apply changes so the two exits stay separate.
- Start the proxy core without waiting for the main window, so login and
  `mclashctl` launches prepare the host before publishing automation
  endpoints.

The release is Apple Silicon-only. MClash still does not enable TUN by
default.
