# MClash 1.4.13

This patch carries the 1.4.12 unified configuration rework and hardens the
release verification path.

- Imported profiles provide node connection data only; MClash owns rules,
  rule sets, strategy groups, DNS, entrances, and runtime output.
- Rule, Global, and Direct modes, named independently targeted HTTP/SOCKS5
  entrances, App Routing as an entrance switch, and the Node Selection
  hierarchy are available from the primary configuration surfaces.
- Rules and traffic monitoring use the Rockxy-inspired table/inspector flow,
  with stable snapshots and reviewed quick actions for domains, apps, and
  processes.
- Mihomo validation covers GEOIP, GEOSITE, IP-CIDR6, PROCESS-NAME/PATH,
  listener targets, disabled rule sets, and safe rollback.
- Release integration now authenticates the read-only MetaCubeX GEO data
  download on shared GitHub runners, avoiding REST API rate-limit failures.

The release is Apple Silicon-only and requires the bundled Mihomo Alpha core.
