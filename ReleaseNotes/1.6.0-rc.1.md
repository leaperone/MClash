# MClash 1.6.0-rc.1

这是 1.6 的首个测试版本，默认代理内核改为 Xray-core 26.9.9 预发行版。MClash 继续管理节点来源、节点组、规则、DNS、入口和工作区。

- 保留 1.4 的配置工作台。订阅只提供节点，订阅中的规则和 DNS 不接管工作区。
- 支持手动选择、自动 Fallback、URL-test、负载均衡和 Relay 节点组。
- 自动组可以设置测速 URL、预期 HTTP 状态、超时、切换与恢复阈值，以及延迟容差。
- 节点组选择由 MClash 管理，Xray 执行代理协议和流量转发。切换出口影响新连接，已建立的连接继续使用原出口。
- 无效节点来源在写入前被拒绝。规则更新失败时恢复之前的运行状态和配置。
- HTTP、SOCKS5、macOS 系统代理和 App Routing 继续使用现有入口。

此版本用于测试，不进入稳定版自动更新。需要 Apple Silicon 和 macOS 14 或更新版本。

不支持的节点协议与传输选项会显示诊断，不会自动改用另一内核。TUIC 和未知插件不在本版 Xray 适配范围内。Hysteria2 配置可由固定版本内核校验，真实服务兼容性仍需逐个验证。

Xray 不提供 Mihomo 格式的连接列表或 API 日志流。App Routing 的捕获记录与核心进程日志仍可分别查看。发布证据会区分本地入口测试、公共网络探测和系统 Network Extension 激活测试。
