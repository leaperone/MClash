# MClash 1.5.7

This patch adds the first verified native GEO database implementation.

- The bundled v2fly `GeoIP.dat` protobuf is decoded directly by MClash with
  bounded varints, length-delimited fields, IPv4/IPv6 CIDRs, unknown-field
  skipping, and a 32 MiB safety limit.
- Native routing evaluates GEOIP country rules against an indexed database
  loaded once and shared by the engine. Loading is lazy, so configurations
  without GEO rules do not parse the 17.8 MB snapshot.
- Runtime diagnostics report `geoDatabase.status` and revision, distinguishing
  a genuine no-match from an unavailable database.
- The real bundled `GeoIP.dat` was parsed during validation and correctly
  matched `223.5.5.5` as CN.

GeoSite, metadb, MaxMind/MMDB, MRS, Reality/XTLS, and full Hysteria2 wire
interoperability remain explicit follow-up work.
